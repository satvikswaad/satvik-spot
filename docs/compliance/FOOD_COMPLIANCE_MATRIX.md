## 1. Product Food Compliance Attribute Matrix

| Mandatory Attribute | Requirement Specification | Satwik Spot Canonical Value | Status / Action Required |
| :--- | :--- | :--- | :--- |
| **FSSAI Licence Number** | 14-digit FSSAI registration/licence number | `OWNER INPUT REQUIRED` | Owner to provide official FSSAI licence number. |
| **FSSAI Licence Category** | Manufacturer / Relabeller / Marketer | `OWNER INPUT REQUIRED` | Owner to confirm licence category. |
| **GSTIN Number** | Tax identification number | `OWNER INPUT REQUIRED` | Owner to supply GSTIN for tax invoice generation. |
| **Brand Name** | Brand name registered on marketplace | `Satwik Spot` | Confirmed. |
| **Vegetarian Logo Mark** | Green dot symbol declaration | `Yes (100% Pure Vegetarian)` | Confirmed. |
| **Ingredients Declaration** | Full raw ingredients list | Mango, Mustard Oil, Salt, Spices | Confirmed for Mango Pickle. |
| **Allergen Information** | Specific allergen warnings | Contains Mustard Oil & Seeds | Confirmed. |
| **Net Quantity / Weight** | Net weight declaration | `500g` (Single Variant Baseline) | Confirmed. |
| **MRP (Maximum Retail Price)** | Maximum retail price (inclusive of taxes)| Printed MRP per SKU | Confirmed (e.g. ₹320 for Mango Pickle). |
| **Selling Price** | Channel listing price (<= MRP) | Channel specific (e.g. ₹249) | Confirmed. |
| **Shelf Life** | Best before timeframe from packing | 12 Months | Confirmed. |
| **Country of Origin** | Manufacturing origin | India | Confirmed. |

> [!IMPORTANT]
> **Legal Disclaimer**: Marketplace listing publication is strictly blocked until all items marked `OWNER INPUT REQUIRED` are populated with verified legal information.
